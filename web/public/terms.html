Terms of Use

Last updated: 1 November 2026

Horizon Translator is a free community tool that converts Fabric mods and Iris/OptiFine shader packs so they can run in Horizon. It is this website and the Horizon Translator app for Windows (together, "the tool"). By converting a file, downloading the app, or using a converted file, you agree to these terms. If you don't agree, don't use the tool.

1. Only convert what you're allowed to

  • Only convert a mod or shader pack if you made it, or if its licence or its author allows you to modify it.
  • The mod converter checks a mod's licence and refuses mods that are All Rights Reserved, "no derivatives", or have no clear licence. That check reads what the file says about itself and can be wrong. Making sure you have the right to convert a file is your responsibility, not the tool's.
  • The app's "I made this mod" option is only for a mod's own author. Using it for someone else's mod breaks these terms and may break the law.
  • Don't use the tool to get around a licence, copy someone else's work, or pass it off as your own.

2. Converted files are for your own use

  • Converted files are a modified version of someone's work. Use them yourself, and only share them if the original licence allows sharing modified copies. Most shader pack licences don't.
  • Credit the original authors as their licence asks. Conditions found by the licence check are listed in the converted mod's PORTING.md.

3. No warranty

  • Converted mods are native code compiled into your game. Read what you build and only build mods you trust. Keep backups of your worlds and files.
  • The Windows app isn't code-signed. Only download it from this site or the project's GitHub Releases page.

4. Your files and privacy

  • Your files are never uploaded. Shader packs are converted inside your browser and mods inside the app on your own computer. Decompiled code is deleted as soon as a conversion ends.
  • The site doesn't use accounts, cookies or tracking. It is hosted on GitHub Pages, and loads two small libraries from public CDNs (jsDelivr and cdnjs), which see your visit like any website would.
  • The app works offline. It only goes online when you click a link, which opens in your browser.

Complaints are taken seriously and handled as quickly as possible. The tool never receives or stores the files people convert, so there is usually nothing stored to remove, but the converters' behaviour can be changed (for example, to refuse a specific mod or pack).
