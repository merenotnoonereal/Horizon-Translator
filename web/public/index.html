Horizon Translator for Windows

Mods are converted by a free desktop app, so everything runs on your own PC and nothing is uploaded. It has the same menu as this site and converts shader packs too.

How to use it

  1. Run HorizonTranslator-Setup.exe. The installer isn't code-signed, so Windows may show "Windows protected your PC": click More info → Run anyway. Only do this with the file from this site or the project's GitHub Releases page.
  2. Open Horizon Translator, pick the Mods tab and drop in a Fabric mod .jar.
  3. Press Convert mod. The result is saved in Documents\Horizon Translator.
  4. Read PORTING.md, then build it into Horizon: horizon-launcher native-build <folder>/mixins/<modid> --trust-native-code. Only build mods you trust: native mods have full access to your computer.

The app only decompiles mods whose licence allows it (MIT, Apache, GPL, LGPL, MPL, OSL and similar). All Rights Reserved mods are only converted for their author ("I made this mod").

By downloading you agree to the Terms of Use: only convert files you're allowed to modify.

Works with packs like BSL, Complementary, Bliss, Photon, Noble, Mellow, MakeUp, Solas and Super Duper Vanilla. Converting takes from a few seconds to a few minutes for big packs.

How it works

      

        

          
Mods: Fabric → Horizon native mod

          
    
            
  1. Licence check. Reads fabric.mod.json and any licence file. Open licences pass; All Rights Reserved is refused.
    2. 
            
  2. Decompile. Turns the jar back into Java with Vineflower. The Java stays on your PC and is deleted straight away.
    3. 
            
  3. Map the mixins. Each @Inject, @Redirect, @ModifyArg… is matched to the Horizon function that does the same job, using a mapping table and Horizon's own source.
    4. 
            
  4. Translate Java to Rust. Config, keys, HUD and tick code, maths, JSON, regex, streams and more become Rust that calls Horizon.
    5. 
            
  5. Write a bundle. A horizon-mixin.toml bundle you build into the game with the Horizon launcher, plus PORTING.md listing anything left to do.
    6. 
          

        

        

          
Shaders: Iris/OptiFine → Horizon pack

          
    
            
  1. Load it like the game does. Runs Horizon's real shader loader (GLSL → naga → SPIR-V) offline, for every dimension, and lists each program it would skip.
    2. 
            
  2. Fix what fails. Tries about 20 rewrite rules on the GLSL (3D textures, compute passes, out-arguments, buffer formats…). A rule is kept only if more programs load and nothing that loaded breaks.
    3. 
            
  3. Fix how it draws. Passes that work around differences in how Horizon renders: normals, matrices, missing uniforms, cleared buffers, noise textures, skies.
    4. 
            
  4. Write the pack. A -horizon.zip for Horizon's shaderpacks folder, with a report of every change.
    5.

FAQ

      
How do I install a converted shader pack?
        
Put the downloaded …-horizon.zip in %APPDATA%\horizon\shaderpacks (Windows) or ~/.local/share/horizon/shaderpacks, then pick it in Options → Horizon Settings → Shader Packs.

      
How do I install a converted mod?
        
Unzip the bundle. Horizon native mods are compiled into the game, so build it with the Horizon launcher:
        horizon-launcher native-build <bundle>/mixins/<modid> --trust-native-code.
        Only do that for code you trust: a native mod runs with full access to your computer. Read PORTING.md first.

      
Will every feature of my mod work?
        
Probably not. The mod converter is meant to help you port a mod, not do it 100% for you. Code that only uses plain Java converts well. Code that reaches deep into Minecraft (custom screens, entity renderers, resource packs) often has no Horizon equivalent yet. Those parts are switched off and listed in PORTING.md, so the mod still loads.

      
Do you keep my files?
        
Your files never leave your computer. Shader packs are converted inside your browser (WebAssembly) and mods by the desktop app on your PC, so nothing is uploaded and there's no server that could keep anything. Decompiled Java is deleted as soon as a conversion ends.

      
Something went wrong. How do I report it?
        
Open an issue on GitHub, or press Report a problem under a result to start one with the details filled in.
        Say which mod or shader pack (with a download link), what you expected, and paste the converter log. Don't attach mods or packs you aren't allowed to share.

      
Is this official?
        
No. It's a community tool and isn't made by the Horizon, Fabric, Iris or OptiFine teams, or by Mojang or Microsoft.
